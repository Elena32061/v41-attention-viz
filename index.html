来源与限定

维度来源

model.js 里 CFG 的每一项都抄自 checkpoint 的 config.json → text_config，字段名原样保留。 1792 = 1280 + 512、32768 = 64×512、 O_A 每组 4096 = 64×512÷8、O_B 的 K = 8×1024 这些换算，以及哪一维被 TP 切，来自实现源码。

稀疏两级

sparse_stage=2。第一级按 candidate_topk_blocks=2048 × candidate_block_size=8 取候选；第二级 MQA indexer（index_n_heads=32、 index_head_dim=128）从候选里选 index_topk=512 个 token（源码里是 self.topk_tokens = cfg.index_topk，单位是 token 不是 block）。

这里没有的东西

  • 没有任何实测时间、吞吐或 TPOT。瓦片数和 wave 数是理想排布的算术结果， 不含 L2、尾效应、graph padding 和 kernel 本身的瓦片形状差异。
  • O_A 实际 kernel 的瓦片不是 128×128，这里按统一口径算，只用于比较量级。
  • 只画 attention。MoE、mHC、shared expert、Engram 表都没有画。
  • wave 数假设每个瓦片代价相同，实际不是 —— K 不同的投影每块的活差很多。
